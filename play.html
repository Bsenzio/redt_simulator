REDT Simulator

Try a cloud passing over a solar panel

Download example CSV

1. Load the example

Download the example CSV below. In REDT, select Start simulator, then Simulation. In Data, choose Open training file and select redt-mppt-example.csv. Keep Use timestamps enabled. The file contains 121 one-second samples with a simulated cloud passing from about 30 to 70 seconds.

In Plot → Full series, select irradiance to see the drop and recovery before pressing Play.

2. Train on the CSV

Open Training. If this is your first file, the counter should show Train on 1 of 1. Press Train MPPT. REDT uses the file’s light and temperature data to fit a voltage target derived from its simulated I–V curve.

Try Generate variants to create synthetic profiles with the same timestamps. For independent evaluation, reserve a different measured day and keep it out of training.

3. Configure the panels

Open Field. For a simple trial, choose one panel and switch the MPPT scope to isolated panel. For an array trial, set Rows and Columns up to 5×5 and select series string. Use the matrix to focus or mark panels and adjust Tilt, connection and model assignment.

Use Camera and Heat map to inspect the field. Weather controls let you test manual conditions such as cloud cover, wind and sun angle.

4. Replay the cloud event

In Compare, choose a 60 s Energy period before starting. Use Data → Restart file to return to the beginning, then press Play. The simulator evaluates every controller on the same conditions.

At 60 simulated seconds the Wh totals stop accumulating. Try Full run to include the recovery after the cloud.

5. Read the results

Compare shows power now (W) and energy accumulated during the selected interval (Wh). Open Power charts and look for the dip near the cloud event. Compare P&O, hill climbing, PID, fixed voltage and the trained model.

This example replays the training file. To test generalization, replay a separate measured file. PID follows the simulated MPP reference.

6. Explore and export

Use Plot to switch between environment, measurements and MPPT curves. Full series compares the input files, and Training → Models and validation shows classifier results. The Physical Twin view exposes readings and logs for the instrument.

Use the desktop version for live UDP and file dialogs to save comparisons as CSV or JSON and export the trained model.

The simulator files are being prepared.

For keyboard controls, click inside the simulator first. The browser version uses sample data or local files. Live UDP requires the desktop version.
